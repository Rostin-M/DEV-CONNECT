# 🚀 DevConnect

**DevConnect** es una aplicación móvil construida con Flutter que permite a desarrolladores compartir sus proyectos, descubrir trabajos de otros programadores y conectarse con la comunidad tech.

## ✨ Características

### 🔐 Autenticación

- Registro de usuarios con correo electrónico y contraseña
- Inicio de sesión seguro
- Recuperación de contraseña
- Perfil de usuario personalizable

### 📱 Gestión de Proyectos

- Crear y publicar proyectos con múltiples capturas de pantalla
- Subida de imágenes a Cloudinary
- Etiquetas (tags) tecnológicas personalizadas
- Enlace a repositorio de GitHub
- Feed principal con paginación infinita
- Sistema de likes

### 👤 Perfiles de Usuario

- Visualización de perfil personal
- Edición de biografía y habilidades
- Actualización de foto de perfil
- Galería de proyectos del usuario

### 🎨 Interfaz de Usuario

- Modo claro y oscuro
- Diseño responsivo
- Animaciones fluidas
- Componentes reutilizables
